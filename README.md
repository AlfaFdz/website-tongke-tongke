# Tongke-Tongke Mangrove Park

Website informasi wisata Hutan Mangrove Tongke-Tongke yang dibuat sebagai project pemrograman web.

## Tentang Project

Website ini dibuat untuk menyajikan informasi mengenai wisata Hutan Mangrove Tongke-Tongke secara terstruktur dan mudah dipahami. Website menampilkan informasi destinasi, aktivitas, galeri, lokasi, serta fitur feedback pengunjung.

## Fitur

- Informasi wisata Hutan Mangrove Tongke-Tongke
- Informasi aktivitas wisata
- Galeri foto
- Informasi lokasi
- Form feedback pengunjung
- Tampilan responsif
- Navigasi antarbagian halaman

## Teknologi

- HTML
- CSS
- JavaScript
